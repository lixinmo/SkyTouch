# 凌触 SkyTouch

凌触将手柄按键和摇杆映射为屏幕操作，支持点击、连点、滑动、宏和体感拉视野。通过配置 App 编辑方案，进入游戏后用浮标切换方案。

当前分支为 1.0。[凌触 2.0](https://github.com/lixinmo/SkyTouch/tree/skytouch-2.0) 增加了手机实体按键映射和手机原生体感，两种模式可以共用方案。

## 使用

需要 RootHide 环境。当前适配 iPhone 15 Pro Max / iOS 17.1，支持飞智黄蜂 2 Pro 手柄。

安装包可从[下载页面](https://github.com/lixinmo/SkyTouch/actions?query=branch%3Amain)最近一次成功记录的 Artifacts 中获取，解压后用 Sileo 安装 `.deb`。

1. 连接手柄，打开凌触，选择游戏。
2. 将手机横屏，下载飞智云方案或编辑本地方案。可以加载游戏截图作为背景，调整按键位置。
3. 保存并选中方案，返回首页开启映射，再进入游戏。
4. 点击浮标切换本地方案，也可以打开凌触或关闭映射。

当前选中的方案全局生效。未连接手柄时，仍可使用上次连接的手柄类型编辑方案。

## 配置管理

在“管理配置”中备份、恢复或清除方案、截图和设置。再次备份会覆盖上一次备份，重要备份可以通过 Filza 另存。

普通卸载会保留配置和备份。若要彻底清除，先在 App 中使用“清除配置”，再卸载凌触；清除配置也会删除手机上的备份。

## 实现思路

凌触沿用飞智的配置界面、方案格式和映射引擎，由系统触屏服务发送映射生成的触点。映射服务独立于配置 App 运行，进入游戏后继续处理手柄输入；浮标用于随时切换方案和关闭映射。
