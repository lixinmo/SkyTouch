# 凌触 SkyTouch 2.0

凌触将手柄或手机实体按键映射为屏幕操作，支持点击、连点、滑动、宏和体感拉视野。通过配置 App 编辑方案，进入游戏后用浮标切换方案。

## 操作模式

**手柄模式**使用手柄的按键和摇杆，默认转动手机控制体感视野，也可以切回手柄原体感。

**手机模式**无需连接手柄，使用操作按钮、音量键和侧边按钮触发方案动作，转动手机控制体感视野。四个实体键可以自定义绑定，默认对应：

| 手机按键 | 方案按键 |
| --- | --- |
| 操作按钮 | LB |
| 音量＋ | A |
| 音量− | B |
| 侧边／锁屏按钮 | LT |

手机模式的映射生效时，这四个键执行方案动作；关闭映射后恢复系统功能。若要正常调音量或锁屏，可先通过浮标关闭映射。

两种模式共用方案。手机模式下，轮盘和依赖摇杆的动作不参与执行；切回手柄模式后恢复，原有按键位置、动作和灵敏度设置继续保留。

## 使用

需要 RootHide 环境。当前适配 iPhone 15 Pro Max / iOS 17.1，手柄模式支持飞智黄蜂 2 Pro。

安装包可从[下载页面](https://github.com/lixinmo/SkyTouch/actions?query=branch%3Askytouch-2.0)最近一次成功记录的 Artifacts 中获取，解压后用 Sileo 安装 `.deb`，再重新加载桌面。

1. 打开凌触，在“输入模式与手机按键”中选择模式，设置按键绑定和体感来源。
2. 选择游戏，将手机横屏，下载飞智云方案或编辑本地方案。可以加载游戏截图作为背景，调整按键位置。
3. 保存并选中方案，返回首页开启映射，再进入游戏。
4. 点击浮标切换本地方案，也可以打开凌触或关闭映射。

当前选中的方案全局生效。编辑方案或输入设置时会暂停映射，切换模式前请先松开按键。手机模式支持手柄和半柄方案，键鼠方案不适用。

选择手机体感后，视野跟随手机转动。手机体感已按手柄的输入幅度校准，基础灵敏度默认 1 倍，可在输入设置中调整；方案里的横纵灵敏度和反向设置仍然生效。两种模式共用这组手机体感设置。

## 配置管理

在“管理配置”中备份、恢复或清除方案、截图和设置。再次备份会覆盖上一次备份，重要备份可以通过 Filza 另存。

普通卸载会保留配置和备份。若要彻底清除，先在 App 中使用“清除配置”，再卸载凌触；清除配置也会删除手机上的备份。

## 实现思路

凌触沿用飞智的配置界面、方案格式和映射引擎，由系统触屏服务发送映射生成的触点。输入来源与方案执行分开，因此同一套方案既能由手柄触发，也能由手机按键触发；体感来源也可以独立选择。
